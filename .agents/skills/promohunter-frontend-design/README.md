# PromoHunter Frontend Design Skill

## Recommended: project installation

Copy this directory to:

```text
<project>/.agents/skills/promohunter-frontend-design/
```

The final path must be:

```text
<project>/.agents/skills/promohunter-frontend-design/SKILL.md
```

Use this option for PromoHunter because the skill is specific to this project's
stack and visual identity. The skill can be committed to Git with the project.

## Optional: global installation

Copy this directory to:

```text
$HOME/.agents/skills/promohunter-frontend-design/
```

On Windows PowerShell the final path is typically:

```text
$HOME\.agents\skills\promohunter-frontend-design\SKILL.md
```

Use the global option only if you want this PromoHunter design language available
in every repository.

## After installation

Codex normally detects skill changes automatically. If the skill does not appear:

1. Start a new Codex chat.
2. Restart the Codex extension or PyCharm.
3. Run `/skills` and verify that `promohunter-frontend-design` is listed.

## Usage examples

```text
Use $promohunter-frontend-design and redesign the promotions page.
```

```text
Use $promohunter-frontend-design to polish the selected restaurant bottom sheet.
Preserve the current API behavior.
```

Codex may also select the skill automatically when the request matches its
description.
